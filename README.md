# LimixProtocol

**Менеджер обхода DPI-блокировок для Windows** с современным интерфейсом в стиле «жидкого стекла», автоподбором стратегий и самоисправлением.
**A DPI-bypass manager for Windows** with a liquid-glass UI, strategy auto-select and self-repair.

## Возможности

- **Сервисы одним переключателем:** YouTube, Discord, Telegram, WhatsApp, Instagram, Facebook, ChatGPT, Gemini, Claude, TikTok, X, Twitch, Spotify, SoundCloud, Reddit, Pinterest.
- **Свои домены и исключения** — применяются на лету, импорт/экспорт `.txt`.
- **5 стратегий + Автоподбор:** программа сама проверяет все методы и выбирает рабочий для вашего провайдера.
- **Диагностика и самоисправление:** находит типичные причины поломки (права, антивирус, блокировка файлов Windows, конфликтующие программы, залипший драйвер, DNS, «Целостность памяти»), чинит что может и понятно объясняет остальное. Отчёт для обращения копируется в один клик.
- **Статус сервисов** на главной: после включения видно, что реально открывается.
- **Оформление:** эффект стекла (выкл / мягкий / сильный), тема системная/тёмная/светлая, 9 цветов, острые/мягкие/круглые углы, анимации переходов, язык RU/EN, кнопка «поверх всех окон».
- **Тихий автозапуск** с Windows без окна и без запроса UAC; значок в трее; перезапуск движка при сбое.
- **Проверка целостности** файлов движка (SHA-256).

## Как это работает (честно)

LimixProtocol — **оболочка-менеджер**: пакетную работу выполняет движок `winws.exe` с драйвером WinDivert из папки `bin`, а программа управляет им (сервисы, списки, стратегии, диагностика, автозапуск).

Обход DPI **ничего не шифрует и не меняет ваш IP**. Он меняет способ отправки пакетов, чтобы оборудование провайдера не опознало сайт. Поэтому:

- если сервис заблокирован **по IP-адресу** (часто Telegram, Instagram, Facebook), одного обхода может не хватить;
- если сервис сам **ограничивает доступ по стране** (так делают ChatGPT, Gemini, Claude в ряде регионов), обход DPI не поможет — нужен VPN.

2. Положите рядом папку **`bin`** с файлами движка: `winws.exe`, `WinDivert.dll`, `WinDivert64.sys`, `cygwin1.dll`, `*.bin`.

## Если что-то не работает

Откройте вкладку **«Диагностика» → «Проверить и исправить»**. Типичные причины:

| Симптом | Причина | Что делать |
|---|---|---|
| Не запускается, «нет прав» | Нет прав администратора | Запустить от имени администратора |
| Файлы пропали из `bin` | Антивирус удалил драйвер | Восстановить из карантина, добавить папку в исключения (есть кнопка) |
| Ошибка 1275 / драйвер заблокирован | «Целостность памяти» Windows или антивирус | Отключить в «Безопасность Windows → Изоляция ядра» |
| Ошибка 577 | Windows не принял подпись драйвера | Проверить Secure Boot и целостность `WinDivert64.sys` |
| Ошибка 1060 / 1072 | Драйвер помечен на удаление | Перезагрузка или «Сбросить драйвер WinDivert» |
| Сайт не открывается | Стратегия не подходит провайдеру | «Стратегии → Автоподбор» |
| Не открывается даже после этого | Блокировка по IP или по стране | Нужен VPN/прокси |

**Сообщить о проблеме:** «Диагностика → Сообщить о проблеме» копирует отчёт и открывает форму обращения — вставьте отчёт туда.

## Для разработчиков

- Код: C# 5 / WPF, один файл `Limix.cs` + интерфейс `ui.xaml` (встраивается в exe).
- Сборка: `build.bat` (использует `csc.exe` из .NET Framework 4.x, входящего в Windows).
- Темы и стекло — динамические ресурсы XAML, переключаются без перезапуска.

## Сторонние компоненты

Движок и драйвер в папке `bin` принадлежат их авторам и распространяются на их собственных условиях. Сохраняйте их лицензии и указывайте авторство, если распространяете сборку.

## English

LimixProtocol is a Windows manager for DPI-bypass: it controls the packet engine and WinDivert driver you place in `bin\` and adds services, domain lists, 5 strategies with auto-select, diagnostics with self-repair, a liquid-glass UI, silent autostart and file integrity checks.

**Quick start:** put the project files and your `bin\` folder together, run `build.bat` (uses the compiler built into Windows), then run `LimixProtocol.exe` as administrator.

**Limits:** it does not encrypt traffic or change your IP. Services blocked by IP address or restricted by country (e.g. ChatGPT, Gemini, Claude in some regions) need a VPN.

**Problems?** Health tab → *Check & fix*, then *Report a problem* to copy a ready-made report.
