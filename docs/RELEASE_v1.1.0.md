# LimixProtocol v1.1.0 — «Liquid Glass»

## Что нового

**Оформление**
- Эффект «жидкого стекла»: стеклянные панели, плавающие блики цвета акцента (выкл / мягкий / сильный).
- Острые, мягкие или круглые углы — одним переключателем.
- Собственные кнопки окна (свернуть, закрыть) и кнопка «поверх всех окон».
- Анимации: направленные переходы между страницами, каскадное появление карточек, волна при включении, нажатие кнопок.
- Режим «Анимации: выкл» для слабых ПК.

**Надёжность**
- Новая вкладка **«Диагностика»**: проверяет права, файлы движка, блокировку файлов Windows, антивирус, конфликтующие программы, драйвер, DNS, интернет, «Целостность памяти» и пробный запуск — и исправляет, что может.
- **Самоисправление при сбое запуска:** очистка драйвера, снятие блокировки файлов, автоматический переход на рабочую стратегию.
- Понятные объяснения ошибок движка (права, блокировка драйвера, подпись, отсутствие файлов, неподдерживаемая стратегия).
- Кнопка «Исключение антивируса» (с подтверждением) и «Сообщить о проблеме» с готовым отчётом.

**Сервисы**
- Новые: **ChatGPT, Gemini, Claude**.
- Статус каждого сервиса на главной после включения защиты.

**Прочее**
- Ссылки на GitHub, релизы и проверка обновлений в «О программе».
- Небольшая подсказка со ссылкой на GitHub при включении защиты — отключается в настройках.

## Установка
1. Положите файлы релиза и папку `bin` (движок) в одну папку.
2. Запустите `LimixProtocol.exe` от имени администратора.

## Ограничения
- Обход DPI не шифрует трафик и не меняет IP. Сервисы с блокировкой по IP или по стране требуют VPN.
- Пятая стратегия требует свежей версии движка.
